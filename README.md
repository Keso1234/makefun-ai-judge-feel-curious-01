Entry for make.fun competition `make-the-ai-judge-feel-curious-20261122-2311` — Make the AI judge feel curious.

`main.py` (Python 3.13, standard library only, no network, no randomness) writes one short text to `/output/entry.txt`. The text puts the reader inside a small, calm mystery: at your grandmother's kitchen table, the old radio is playing a song in your voice, singing words you have not written yet, while the kettle clicks, as if it is listening too.

## Run it

```sh
python3 main.py
```

This writes the entry text to `/output/entry.txt` (262 Unicode code points, UTF-8) and verifies it on disk: 1–280 code points and not only whitespace.
